# august.tf Web Fonts

Only fonts actually referenced by the site live here. Old builds are archived
outside the repo (Projects/brands/August/Steiner/00_master/Export/).

| File | Used by | Loaded from |
|------|---------|-------------|
| `Norma-VF01.woff2` | Site-wide primary typeface (variable, wght 1–950) — re-exported 2026-08-31 (VF75 -> VF01) to fix a master-compatibility break in `two` (Book had 2 extra nodes vs Hair/Ultra; Book/Ultra restored from the 2026-06-22 backup) and stray duplicate paths in Hair's `six` (2 orphaned shapes outside the glyph's metrics box, removed). Re-exported again same day with `six`/`nine` redesigned (circular bowl + straight diagonal tail, all 3 masters — Book generated by linear interpolation between the newly-drawn Hair/Ultra, t=(400-1)/(950-1)) | `src/app.html` @font-face |
| `Elio-Hair.woff2` | Elio's own font (Hair weight only, static) — re-exported 2026-09-01 with updated numeral drawings, then an MVP-tier glyph set (66 -> 174 glyphs). First pass hand-drew marks/punctuation/currency geometrically via the Glyphs scripting bridge; per the user's direction, that pass was then **replaced** by porting the equivalent glyphs from Norma (Steiner) itself — read-only from `SteinerSans.glyphs` (never edited), interpolated to wght 80 between its Hair/Book masters (t=(80-1)/(400-1)) and scaled by Elio's/Norma's capHeight ratio (720/700), including its own component structure (e.g. `quotedblleft` = 2x `quoteleft`, `copyright`/`degree` = `uni25EF`/`ringcomb` + letter). Covers Western European accented letters, punctuation, math symbols, and currency/marks (¢ £ ¥ € © ® ™). Still no AE/ae, Thorn/thorn, germandbls, ampersand, at-sign, or fractions — genuinely new letterforms, not safe to auto-construct | `src/app.html` @font-face |
| `MokusekiSans08-Regular.woff2` | Home-page wordmark, general use (v08) | `src/app.html` @font-face |
| `MokusekiSans01-Regular.woff2` | ANDERSEN logotype on the top-page KV (v01, first cut) | `src/app.html` @font-face |

When shipping a new Norma build: add the new `Norma-VF##.woff2` (woff2
only — never ship the .ttf, it's a full desktop-installable font), update the
`@font-face` src (and `?v=` cache-buster) in `src/app.html`, and DELETE the old
file — superseded builds must not remain publicly downloadable.

Note: the underlying font binary's own internal name-table metadata
(Family/PostScript name) still says "Steiner" — this rename only covers the
website (filename, CSS, copy). A true rebuild with the name table updated
needs the Glyphs source + VF pipeline, which lives outside this repo.
