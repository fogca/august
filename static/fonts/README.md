# august.tf Web Fonts

Only fonts actually referenced by the site live here. Old builds are archived
outside the repo (Projects/brands/August/Steiner/00_master/Export/).

| File | Used by | Loaded from |
|------|---------|-------------|
| `Norma-VF05.woff2` | Site-wide primary typeface (variable, wght 1–950) — re-exported 2026-09-07. History: VF03 tightened `t`'s sidebearing; VF04 redrew `t`'s own outline (13+5 nodes across all 3 masters now, was 10+4); **VF05** refines `t`'s outline again — width and all 985 kerning pairs unchanged, confirmed by a full byte-diff that `t` is the only glyph that changed since VF04. `baht` and `ogonekcomb` remain excluded (still genuinely master-incompatible — verified with a scan that checks per-path NODE counts, not just shape/path counts: `ogonekcomb`'s single path has 14/11/17 nodes across Book/Ultra/Hair, so a shape-count-only scan can wrongly read it as "fixed" since the path *count* does match; ogonekcomb's exclusion still cascades to Aogonek/Eogonek/Iogonek/Uogonek + `.smcp` + lowercase + standalone `ogonek`, which reference it as a component); `germandbls`/`S.ss.08` remain excluded as before (empty in 2 of 3 masters, glyphsLib skips these silently rather than hard-erroring). Name table still correctly says "Norma" (VF02's fix, see the note below). | `src/app.html` @font-face |
| `Elio-VF11.woff2` | Elio's own variable font — 2 masters, Hair (wght 150) / Ultra (wght 850). Early history (VF01-10): renamed from Asta, first Ultra composites wired up, mark-anchor bug fixed, kerning added, web-equivalent default letter-spacing baked in (Hair +0.04em/Ultra +0.02em). **VF11** (2026-09-14) is a big compatibility jump: all 4 remaining Hair-only combining marks (dieresiscomb/tildecomb/ringcomb/cedillacomb) are now drawn in Ultra, so every Adieresis/Atilde/Aring/Ccedilla-type composite ships for the first time (22 letters) — plus all 10 digits, `colon`, and `emdash`. **144 glyphs ship** (measured cmap, up from 107 in VF10). Still excluded: most remaining punctuation (`quotedblleft`/`quotedblright`/`quoteright`/brackets/etc. — their own Ultra shapes are unfinished), currency symbols apart from cent/dollar/euro (rebuilt via proportional bar reconstruction), and two unencoded stylistic-alternate slots (`three.ss01`, and a new `t.ss01` added this round — the latter is already Hair/Ultra-compatible and ships in the binary, but has no GSUB `ss01` feature wired up yet, so it isn't actually selectable from CSS). The exclusion set is regenerated by a live scan before every build — checking per-path NODE counts, not just shape/path counts (a shape-count-only scan can false-negative — see Norma's `ogonekcomb` row above). The source `.glyphs` file is publicly renamed "Elio" (2026-08-31) but internally still called `Asta.glyphs`, under active parallel work (including from other concurrent sessions on this same repo — double-check for an already-committed build before assuming a version number is free). Built via Glyphs' own `ExportDesignspaceAndUFO` + ufo2ft — glyphsLib's direct `.glyphs` parser errors on this file's format-4 node data, so the designspace/UFO route is required, not the raw-file route Norma's build script uses. Build script: `Projects/brands/August/00_Typeface/Asta/Export/compile_vf.py` (re-run `ExportDesignspaceAndUFO` into `Export/ufo/` first if the `.glyphs` source has been edited since the UFOs were last exported — `compile_vf.py` builds from those UFOs, not the `.glyphs` file directly). | `src/app.html` @font-face |

When shipping a new Norma build: add the new `Norma-VF##.woff2` (woff2
only — never ship the .ttf, it's a full desktop-installable font), update the
`@font-face` src (and `?v=` cache-buster) in `src/app.html`, and DELETE the old
file — superseded builds must not remain publicly downloadable.

Note (resolved 2026-09-05): earlier builds' internal name-table metadata
(Family/PostScript name) still said "Steiner" even after the site-wide
rename to "Norma" — only the filename/CSS/copy had been updated, not the
font binary itself. `build_vf.sh` (in the Glyphs source repo, outside this
one) now takes a 2nd argument for the family base name; VF02 was built with
`./build_vf.sh 02 Norma`, so the binary's own name table says "Norma" too.
